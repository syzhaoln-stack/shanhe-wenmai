# 山河文脉 · 古代汉语研习馆

[打开课程网站](https://syzhaoln-stack.github.io/shanhe-wenmai/) · [直接进入「问古人」](https://syzhaoln-stack.github.io/shanhe-wenmai/#dialogue)

研习馆围绕古代汉语（一）（二）的教学大纲组织知识图谱、文选意象、历史地理和原文字词点读。教材链接标明王力《古代汉语》课程用本的对应页码，供师生对照手中的教材。

在「问古人」选择屈原、孟子或荀子，即可使用免密钥的课文研读。填写个人 DeepSeek API 密钥后，可开启基于课文的 AI 自由对话。浏览器将请求直接发送到 DeepSeek。密钥仅在该页面的内存中使用，刷新或关闭标签页后需要重新填写。
